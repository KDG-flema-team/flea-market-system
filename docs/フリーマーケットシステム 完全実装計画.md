```java
// ReportPriorityService.java の設計例
@Service
public class ReportPriorityService {
    public int calculatePriority(Long reportedUserId) {
        // 同一ユーザーへの通報数
        long reportCount = reportRepository
            .countByReportedUserIdAndStatus(reportedUserId, "PENDING");
        
        // ユーザーの評価
        Double avgRating = starRepository
            .getAverageRatingForUser(reportedUserId);
        
        // 取引数
        long orderCount = orderRepository
            .countByBuyerIdOrSellerId(reportedUserId);
        
        // 優先度計算 (0-100)
        int priority = (int)(reportCount * 20);
        if (avgRating != null && avgRating < 3.0) priority += 30;
        if (orderCount > 100) priority -= 10; // 実績ある人は優先度下げる
        
        return Math.min(100, Math.max(0, priority));
    }
}
```

## 🚦 ステータス定義

### User Status

- `enabled`: true/false (ログイン可否)
- `banned`: true/false (BAN状態)
- `role`: USER, ADMIN
- `rank`: bronze, silver, gold, platinum

### Report Status

- `PENDING`: 未対応
- `REVIEWING`: 対応中
- `RESOLVED`: 対応完了 (措置なし)
- `ACTION_TAKEN`: 対応完了 (BAN等の措置実施)
- `REJECTED`: 却下 (虚偽通報)

### Ban Type

- `PERMANENT`: 永久BAN
- `TEMPORARY`: 期間限定BAN
